# 🔋 Monster Energy - Full-Stack Concept App

> Uma aplicação web full-stack de alta octanagem inspirada na **Monster Energy**. Desenvolvida para explorar a integração entre um front-end dinâmico, um servidor backend em Node.js e um banco de dados relacional MySQL.

## 🚀 Sobre o Projeto

Este projeto consiste em um ecossistema web completo que recria a identidade visual marcante e agressiva da Monster Energy. O diferencial está na arquitetura **full-stack**: o front-end interage com um servidor Node.js que processa dados, consome arquivos **JSON** e realiza operações de persistência em um banco de dados relacional gerenciado via **MySQL (XAMPP)**.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

### **Front-end**
* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização moderna, Flexbox/Grid e identidade visual personalizada)
* **JavaScript (Vanilla)** (Interatividade e manipulação do DOM)

### **Back-end & Banco de Dados**
* **Node.js** (Ambiente de execução JavaScript para o servidor)
* **MySQL / XAMPP** (Gerenciamento do banco de dados local e consultas SQL)
* **JSON** (Formato de intercâmbio de dados)

---

## ✨ Principais Funcionalidades

* **🎨 UI/UX Imersiva:** Design moderno e responsivo com a paleta clássica da marca.
* **🔄 Comunicação Client-Server:** O front-end consome dados do backend de forma dinâmica.
* **🗄️ Persistência de Dados:** Estrutura relacional configurada no MySQL para armazenar informações do sistema.
* **⚡ Ambiente Local Integrado:** Servidor rodando via Node.js conectado ao banco local via XAMPP.
